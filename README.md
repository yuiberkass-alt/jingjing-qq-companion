# 鲸鲸 · JingJing

> 会记事的 QQ 群 AI 群友 / An AI companion for QQ groups and Bilibili DMs.

鲸鲸不是客服机器人，也不是问答机器。她是群里的一个人：温柔、有点软、偶尔犯迷糊。被叫到会应，没人叫就不打扰。聊得多了会记得你，聊错了会改，久不联系的东西会慢慢淡掉。

基于 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 4.29+，模型用 DeepSeek，协议端用 NapCat。

## 她能做什么

### QQ 群聊

- **只在被叫到时说话**。叫名字、@ 她、引用她，才会开口；别人互相聊天她不出声。
- **叫一次能聊几轮**。叫过之后 180 秒内、同一人接着说，她会接；最多连续三轮，然后自己收尾。
- **会收尾**。对方说「嗯」「行吧」「晚安」这类话，她就停；话题转走也停。不会一直追问。
- **会发表情包**。从 112 张图里按语境挑，不是随机贴图。
- **不站队**。政治、宗教、成人话题被拦下，被直接问到也只礼貌回应不展开。有人表达轻生念头时例外——那种情况一定会回应，而且先安抚不讲道理。

### B 站

> 需要单独的插件和鲸鲸自己的 B 站账号。

- **私信收发**：她用自己的号和你聊，风格和 QQ 群里一致。
- **看得懂视频**：你分享 BV 号或 b23.tv 链接，她会去拉标题和简介，再回你，不瞎编。
- **会发 B 站表情**：从账号的表情面板里挑，发送前校验，不会发出乱码。
- **授权后能自己逛 B 站**：搜视频、挑一个、写一句推荐发给你。默认关闭，要你明确说「以后你可以自己逛」才开，说「别逛了」立刻停。
- **评论功能未开放**。

### 记忆

三层结构，彼此隔离：

| 层 | 范围 | 谁能改 |
|---|---|---|
| 核心 | 跨群通用的人格与事实 | 只有你，需要审核 |
| 群 | 某个群的公共记忆 | 自动写入 |
| 成员 | 某个群里的某个人 | 自动写入，按群授权 |

- **自动总结**：每 12 条消息把这段对话读一遍，只留长期有用的事实。
- **会过滤**：关于机器人自身的话、对人的评价、抱怨、敏感信息，一律不进库。
- **会提炼**：同一个人的记忆会重写成一段笔记，不是越攒越多。
- **会纠错**：说「现在更喜欢狗」，旧的「喜欢猫」自动作废归档。
- **会遗忘**：120 天没被强化、只出现一次的，自动归档，可恢复。
- **私聊独立**：QQ 私聊有自己的记忆空间，不和各群混。

### 关系与情绪

- **熟悉度四档**：刚认识 → 逐渐熟悉 → 熟人 → 默契老熟人。每天最多涨 10，一晚上聊再多也升不了级。
- **七类短期情绪**：安慰、傲娇、害羞、得意、认真、开心、平常。有优先级和各自的衰减时间，不会卡在一种情绪里。
- **不做好感度排行**，也不公开任何数值。

## 设计原则

1. 宁可少说，不要多话
2. 宁可少记，不要乱记
3. 核心人格全局唯一，群与群的差异只体现在节奏和话题上
4. 任何自动化都能被一句话关掉
5. 出问题要能回滚，删除永远是软删除

## 记忆是怎么工作的

```
聊天消息
   │
   ├─ 每 12 条 ─→ 总结器 ─→ 候选事实 ─→ 过滤 ─→ 写入
   │                                      ├─ 敏感词拦截
   │                                      ├─ 关于机器人的话拦截
   │                                      └─ 骂人/抱怨拦截
   │
   └─ 每次回复 ─→ 召回（BM25 + 时间新鲜度）─→ 拼进提示词
```

维护动作：

| 动作 | 触发 | 效果 |
|---|---|---|
| 合并重复 | 每次总结后 | 同义内容合成一条，证据数累加 |
| 笔记重写 | 每几轮对话 | 覆盖成一段 120 字以内的画像 |
| 事实推翻 | 新内容标了 replaces | 旧的归档，新的生效 |
| 过期遗忘 | 每天 | 120 天未强化且只出现一次 → 归档 |
| 快照备份 | 每 12 小时 | 保留最近 7 份 |

## 安装

### 1. 前置

- AstrBot 4.29 或更新
- NapCat（或任意 OneBot v11 实现）
- 一个支持函数调用的模型 API

### 2. 放插件

把 `plugins/` 下三个目录整个复制到 AstrBot 的 `data/plugins/`：

```
astrbot_plugin_xiaozhao_smart_mention   聊天行为
astrbot_plugin_jingjing_memory_bridge   记忆
astrbot_plugin_jingjing_bili            B 站
```

### 3. 初始化记忆库

```bash
python3 memory/memctl.py init
```

默认建在 `data/plugin_data/jingjing_memory/memory.sqlite3`。

### 4. 填配置

在 AstrBot 里配置机器人 QQ、群号、模型。最少要改这几项：

```json
{
  "mention_keywords": ["鲸鲸", "大肥鱼"],
  "jj_semantic_group_ids": ["你的群号"],
  "active_reply_enabled": false,
  "bot_qq_ids": ["机器人QQ"]
}
```

`active_reply_enabled` 建议先设 `false`：只在她被叫到时说话。想让她主动参与群聊再打开。

### 5. 重启

```bash
docker restart astrbot
```

## 配置

### 聊天行为（xiaozhao_smart_mention）

| 键 | 默认 | 说明 |
|---|---|---|
| `active_reply_enabled` | false | 是否允许主动接群聊 |
| `mention_keywords` | ["鲸鲸"] | 叫她的名字 |
| `jj_semantic_group_ids` | [] | 生效的群号 |
| `jj_fast_continuation_window_sec` | 120 | 叫完之后多久内还能接着聊 |
| `jj_image_reply_cooldown_sec` | 45 | 两次看图回复的最小间隔 |

### 记忆（jingjing_memory_bridge）

| 键 | 默认 | 说明 |
|---|---|---|
| `enable_recall` | true | 是否召回记忆 |
| `enable_extract` | true | 是否自动记录 |
| `summarize_every_messages` | 12 | 多少条消息总结一次 |
| `max_memories` | 3 | 每轮最多带几条记忆 |

控制台里也有开关：记忆页右上角「自动记忆」，关掉立即生效不用重启。

### B 站（jingjing_bili）

| 键 | 默认 | 说明 |
|---|---|---|
| `poll_interval_sec` | 30 | 私信轮询间隔 |
| `roam_interval_min` | 360 | 允许逛 B 站时两次之间的最短间隔 |

cookie 不写在配置里，通过控制台保存，存在服务器 `plugin_data/jingjing_bili/cookie.json`，权限 600，不回显。

## 日常使用

### 叫她

```
鲸鲸
@鲸鲸 在吗
鲸鲸，帮我看看这个
```

叫完之后可以连着说几句，她会接。最多三轮。

### 让她安静

她不主动说话时，只有叫名字才开口。想彻底停掉主动参与：

```
控制台 → 群设置 → 自动接话 → 关闭
```

### 让她记住

不需要特殊说法。正常聊天，每 12 条会自动总结。想确认记了什么：

```
控制台 → 记忆 → 搜索
控制台 → 笔记 → 看她的画像
```

### 让她忘掉

```
控制台 → 记忆 → 找到那条 → 删除（软删除，可恢复）
```

### 授权逛 B 站

```
私信里说「以后你可以自己逛」   → 打开
私信里说「别逛了」             → 立刻关闭
私信里说「现在去逛逛」         → 只逛这一次
```

## 桌面控制台

```bash
python client/app.py
```

会弹出一个独立窗口（Edge 应用模式），九个页签：

| 页签 | 用途 |
|---|---|
| 记忆 | 搜索、筛选、编辑、删除、提升到核心 |
| 待审核 | 群记忆进核心需要你批准 |
| 群设置 | 群审核、自动接话开关、群相处数据、熟悉度 |
| 状态 | 容器、版本、回复量、行为报告 |
| 笔记 | 她的画像，直接改文本框就能改记忆 |
| 图谱 | 记忆关系图，可拖动摆位置 |
| 账号 | QQ 连接状态、B 站登录 |
| 人格 | 读/改/存人格提示词，支持试聊 |
| 运维 | 备份、整理、体检、重启 |

只监听 `127.0.0.1`，不对外开放，不保存任何密钥。

## 命令行工具

```bash
cd memory

python3 memctl.py init            # 初始化数据库
python3 memctl.py list            # 列出记忆
python3 memctl.py add ...         # 手动加一条
python3 memctl.py graph --group G # 导出关系图数据
python3 memctl.py health          # 体检：重复、过期、可疑
python3 memctl.py consolidate     # 合并重复、刷新群印象
python3 memctl.py stats           # 统计
```

```bash
python3 tools/chat_report.py      # 从日志生成行为报告
```

输出包含：收到多少、回了多少、判定分布、延迟分位、漏接率。

## 隐私与边界

- **按群授权**：一个群审核通过，成员记忆才会开始积累；个人可以单独拒绝。
- **可查可删**：所有记忆在控制台可见，随时能改能删。
- **不记敏感信息**：密码、证件、住址、电话、健康、政治立场、性相关内容，进库前就被拦。
- **不跨群**：A 群的记忆不会出现在 B 群。
- **不偷看私聊**：QQ 私聊的记忆只属于那段私聊。
- **删除是软删除**：标记为删除，不再召回，但记录还在，误删能恢复。

## 已知限制

- **被动优先**：默认不主动参与群聊，需要被叫。想让她活跃得手动开。
- **总结只覆盖她参与的轮次**：群里别人之间聊的内容，她看不到也记不住。
- **B 站评论未开放**：只读不发。
- **微信未接入**：结构里预留了字段，没实现。
- **检索是 BM25**：关键词 + 同义词 + 新鲜度，不是向量检索。问「上次那个番」这类模糊指代可能找不到。
- **样本依赖**：机制齐全，但笔记和画像需要足够对话才准。刚开始用会觉得她记性一般。

## 常见问题

**她会自己冒出来说话吗？**
默认不会。`active_reply_enabled` 关着时，只有叫名字或 @ 她才说话。

**为什么叫了只回一句就没了？**
检查 `jj_fast_continuation_window_sec`。默认 180 秒内同一人接着说会继续接，最多三轮。

**记忆里怎么有奇怪的东西？**
跑 `memctl.py health` 看看，可疑条目会列出来。也可以在控制台直接删。

**B 站发不出私信？**
先看控制台账号页的登录状态。另外新号在被对方回复或关注前只能发一条。

**换了模型或人格会怎样？**
人格是独立的，在控制台改，有版本历史可以回滚。换模型不影响记忆。
