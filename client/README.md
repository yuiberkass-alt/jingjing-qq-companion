# 鲸鲸控制台（桌面客户端）

双击桌面上的 **鲸鲸控制台** 快捷方式即可打开。窗口会以 Edge/Chrome 的应用模式弹出，看起来像独立软件。

## 里面能做什么

- **记忆**：按作用域/群/成员筛选，搜索，新增，编辑，删除/恢复；对群或成员记忆点「提升到核心」
- **待审核**：批准或驳回"群记忆进核心"的申请（只有你批准才会真的写进核心）
- **群设置**：开关某个群的记忆召回、给成员加授权
- **状态**：容器状态、主插件版本哈希、近 6 小时回复数、记忆分布、待审核数、数据库大小
- **运维**：查看最近 20 条回复、一键备份记忆库（服务器快照 + 下载到 D:\Jingjing\backups\memory）、重启 AstrBot（带二次确认）
- **人格**：选人格、读取全文、修改、保存（自动备份旧版）、查看历史版本、**试聊**（不保存也能先看改完什么效果）
- **图谱**：把记忆画成关系图（成员—记忆—类型—关键词），点圆点看原文，可按群筛选
- **账号**：机器人 QQ、QQ 连接记录、NapCat/AstrBot 状态、一键打开 NapCat 登录页（SSH 隧道，仅本机可见）、复制登录 token

## 它怎么工作

- 客户端只监听 127.0.0.1 的随机端口，不对外开放
- 每个操作都是通过已有的 SSH 配置（D:/Jingjing/ssh/config，别名 oJingJing）在服务器上跑一条 `memrpc.py` 命令，参数用 base64 传，中文和空格不会出错
- 不保存任何密钥，不新增服务器端口，不装第三方库

## 文件

- `app.py`：本地 HTTP 服务 + SSH 桥
- `ui/index.html`：界面
- `启动鲸鲸控制台.cmd`：启动器（桌面快捷方式指向它）

## 连不上会怎样

打开时会先做一次连通性检查：SSH 不通就在页面顶部弹红条，写明原因和排查命令，不会给你一个空白列表。所有失败都会记到 `client/console.log`，窗口没控制台也能查。

## 打不开怎么办

1. 先在 PowerShell 里跑 `ssh -F D:/Jingjing/ssh/config oJingJing "echo ok"`，确认能连服务器
2. 再手动运行 `启动鲸鲸控制台.cmd`
3. 仍然不行，用 `python app.py` 直接跑，看控制台报错

## 关掉窗口之后

右上角「退出」会立刻停掉后台服务。直接关窗口也没关系：页面每 2 秒给后台一个心跳，窗口一关，后台 30 秒内自己退出，不会留残留进程。
